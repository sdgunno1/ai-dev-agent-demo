# AI 개발 공정 에이전트 — 서비스 프로토타입

기능 요청(이슈) 한 건을 넣으면 AI가 설계부터 배포 준비까지 진행하고,
사람은 **설계 승인(G1)** 과 **배포 승인(G4)** 두 번만 하는 서비스의 화면 프로토타입입니다.

- ① 이슈 입력 → ② AI 처리(흐름도 · 승인) → ③ 결과
- 검증 리포트: 수용 기준 대조, 확인 사다리, AI 리뷰, API 재생, 기존 API 회귀, 실행 기록
- AI 모델 안내: AI · 실행기 · 사람의 역할, 적용 모델 후보

실제 AI(Pollinations 무료 공개 API, GPT-OSS 20B, API 키 없음)를 브라우저에서 직접 호출하고,
AI가 쓰는 과정을 화면의 AI 작업창에 실시간으로 보여 줍니다. AI 결과는 실행기 검사를 거친 뒤에만 씁니다.

| AI가 만드는 것 | 실행기 검사 |
|---|---|
| 이슈 초안 (한 문장 요청 → 제목 · 유형 · 수용 기준) | 기준 개수, 모호한 표현 |
| 설계 요구사항 · 위험 등급 · 배포 요약 | 수용 기준 반영, 근거 인용 원문 대조, 규칙 판정 하한, 요약 숫자 대조 |
| 코드 변경안 · API 테스트 요청 · 자기 리뷰 | 요구사항 추적 주석, 수용 기준 포함, 리뷰 인용 코드 존재 여부(없으면 보류) |
| PL 질문 답변 | 언급한 파일 · API(메서드 포함)가 실제 목록에 있는지 |

빌드 · 테스트 실행은 가상 '출장관리 시스템'의 시범 실행 데이터로 시뮬레이션합니다.
이슈 · 코드 · 인물 · 조직 정보는 모두 가상 데이터입니다.

- AI 호출: `src/liveAi.ts` (설계 1번 → 설계 승인 후 구현 1번, 설계 반려 시 반려 사유를 넣어 다시), 화면 조각: `src/aiView.tsx`
- 매 호출은 새로 생성합니다(서버 쪽 저장 답 재사용 방지). 저장한 결과는 새로고침 뒤 화면을 되살릴 때만 씁니다.
- 무료 한도는 접속자당 30초에 1회라 직전 호출 후 31초까지 기다렸다가 호출합니다.
- 이 API는 localhost 출처를 막기 때문에 `npm run dev`에서는 시뮬레이션으로 진행되고, 게시 주소에서 실제 AI가 동작합니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 정적 파일 생성
```

빌드한 `dist/` 내용을 `gh-pages` 브랜치에 올려 GitHub Pages로 배포합니다.
